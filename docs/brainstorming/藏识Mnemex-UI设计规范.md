# 藏识 / Mnemex — UI 设计规范

> 视觉方向：深色液态玻璃（Liquid Glass），延续 Drift 的产品视觉语言，但通过单一"呼吸中的记忆核心"作为签名元素，与常见的暗色+荧光色 AI 风格模板做出区分。

---

## 一、设计原则

1. **安静运作，不打扰心流**——所有主动提醒类 UI（关联提醒、模式识别）必须是非侵入的，默认收起，用户主动展开才呈现细节。
2. **玻璃即层次，不是装饰**——半透明面板对应"分层"这个核心技术隐喻（分层摘要、事件溯源），每一层玻璃面板代表一层知识抽象，而非纯粹的视觉效果。
3. **状态诚实**——扫描中/已索引/待处理等状态必须随时可见，用户需要对"系统现在知道什么、还不知道什么"有清晰感知，这是建立信任的基础。
4. **本地优先可见化**——隐私是核心卖点，云端/本地推理状态应该在界面上常驻可见，而不是藏在设置里。

---

## 二、色彩系统

| Token | 色值 | 用途 |
|---|---|---|
| `--bg-base` | `#0B0E14` | 页面基底背景（深炭蓝黑） |
| `--bg-deep` | `#070910` | 更深层背景 / 弹层遮罩 |
| `--glass-fill` | `rgba(255,255,255,0.05)` | 玻璃面板默认填充 |
| `--glass-fill-strong` | `rgba(255,255,255,0.08)` | 玻璃面板 hover / 激活态填充 |
| `--glass-border` | `rgba(255,255,255,0.10)` | 玻璃面板描边 |
| `--text-primary` | `#E8ECF1` | 主文本 |
| `--text-secondary` | `#8B93A1` | 次要文本 |
| `--text-tertiary` | `#565D6B` | 元数据 / 时间戳 / 路径 |
| `--accent-jade` | `#6FE3C4` | 主强调色：记忆核心、已索引状态、正向反馈 |
| `--accent-violet` | `#8A7FFF` | 次强调色：代码关联、关联图谱节点 |
| `--accent-coral` | `#E2725B` | 仅用于警示/错误，克制使用 |

**使用原则**：jade（薄荷玉色）和 violet（紫）分别对应"记忆/知识"与"代码/结构"两条语义线，不做第三种强调色，避免颜色语义稀释。coral 只在真正的错误/风险场景出现，日常状态一律不用红色系。

---

## 三、字体系统

| 角色 | 字体 | 说明 |
|---|---|---|
| 界面标题 / 数字 | Space Grotesk | 几何感强的技术字体，用于 nav、卡片标题、状态数字 |
| 中文正文 | Noto Sans SC | 中文场景下的可读性主字体 |
| 代码 / 路径 / 元数据 | JetBrains Mono | 文件路径、commit hash、时间戳、快捷键提示 |

**字号规范**：
- 卡片标题：14px / 500
- 正文：13px / 400
- 元数据（路径/时间）：11px / mono / 400
- 不使用超过 20px 的标题字号——这是一个工作工具，不是营销页面，克制字号层级。

---

## 四、布局网格

- 整体采用 **76px 侧边栏 + 弹性主区域** 双栏结构，圆角 20px。
- 主区域内部采用 **1.3fr / 1fr** 双列卡片网格，左列信息密度更高（扫描状态、检索结果），右列偏可视化（关联图、主动提醒）。
- 卡片圆角统一 20px，内边距 22px，卡片间距 18px。
- 玻璃层 `backdrop-filter: blur(16–20px)`，避免混用不同模糊值造成视觉层次混乱。

---

## 五、组件规范

### 状态标签（Tag）
- `已索引`：jade 底色 12% 透明度 + jade 文本
- `索引中`：violet 底色 14% 透明度 + violet 文本
- 不使用红色状态标签表示"待处理"——待处理是中性状态，不是错误状态。

### 记忆核心标记（签名元素）
- 34px 圆形径向渐变（白心 → jade → 透明）
- 呼吸动画：`scale(1) → scale(1.12)`，3.4s 缓动循环，亮度同步呼吸
- 必须包裹在 `@media (prefers-reduced-motion: reduce)` 内提供静态降级版本

### 关联图谱 mini 预览
- 核心节点 16px，jade 色，带 14px 模糊光晕
- 关联节点 10px，按语义类型着色（violet=代码关联，jade=文档/历史关联）
- 连线透明度不超过 0.4，避免线条抢夺节点的视觉焦点

### 搜索栏
- 常驻显示快捷键提示（如 `⌘K`），使用 mono 字体、11px、灰色边框小胶囊
- placeholder 文案使用动词开头的具体描述："检索文档、代码或历史决策…"，不用"搜索"这种泛化词

---

## 六、文案原则（对齐 frontend-design 写作规范）

- 站在用户操作的角度命名，例如"正在索引 · 3 个文件"而非"index_queue_size: 3"
- 状态描述用主动语态，"已识别模式"而非"模式已被系统识别"
- 空状态/错误状态需要给出明确的下一步动作提示，而不是单纯报告问题
- 主动提醒类文案要具体到"哪次记录、哪个项目"，避免"发现相关内容"这种模糊表达

---

## 七、无障碍与响应式底线

- 所有可交互元素需要可见的键盘焦点态（focus ring），不能仅依赖 hover
- 动画一律遵循 `prefers-reduced-motion`
- 深色玻璃面板上的文字对比度需满足 WCAG AA（正文文本对比度 ≥ 4.5:1）
- 侧边栏在窄屏下可收起为纯图标模式，主内容区网格在窄屏下退化为单列

---

## 八、图标设计说明

App 图标（`icon.svg`）延续同一视觉语言：
- 深色圆角矩形（squircle）背景
- 中心呼吸光核 + 分层同心圆环，对应"藏识"分层存储的核心隐喻
- 四个外围节点 + 连接线，对应关联图谱能力
- 配色严格复用 jade / violet 双色系统，不引入第三色

---

## 九、补充组件（第二轮设计）

### 关联图谱全屏视图（`graph-view.html`）
- 顶部筛选胶囊（全部/代码/文档/决策记录）复用状态标签的配色逻辑，选中态用 jade 12% 底色
- 画布内节点大小分两级：核心节点 20px（当前查看对象），关联节点 9px；连线透明度按语义相关性递减，不做等粗处理
- 右侧信息面板固定宽度 320px，展示选中节点的元数据、关联摘要与操作项，避免图谱本身承载过多文字

### 隐私与推理设置面板（`privacy-panel.html`）
- "本地优先"卡片默认选中并带"推荐"徽标，视觉上明确传达默认值就是隐私最优选项，而非中立选项
- 强制本地目录用等宽字体展示路径，配合 🔒 标记，颜色使用 coral（本规范中唯一允许 coral 在非错误语境下使用的场景，因为这里传达的是"边界/限制"而非"错误"）
- 不可关闭的开关（如 embedding 本地化）需要明确置灰并降低透明度，防止用户误以为可以关闭核心隐私保证

### 首次运行引导（`onboarding.html`）
- 记忆核心标记放大至 88px 作为页面视觉焦点，外圈叠加两层静态圆环（不参与呼吸动画，避免动效过载）
- 索引进度用状态图标区分「已完成/进行中/等待中」，不用百分比进度条作为唯一指示——文字状态比单一进度条更能传达"系统正在理解内容"而非单纯的文件传输
- 文案基调：把等待转化为信任建立过程，明确说明"这次是全量、以后是增量"，并在底部强调本地处理，呼应隐私卖点

## 十、图标资源

- `nav-icons.svg`：导航图标集（symbol 形式），包含扫描/检索/关联图谱/摘要/设置/隐私/记忆核心共 7 个图标，均使用 `currentColor`，可直接通过 `<use href="nav-icons.svg#icon-graph">` 引用并继承任意文本颜色
- `tray-icon-mono.svg`：菜单栏/系统托盘单色图标，line-only 设计，适配系统深浅主题自动切换
- 图标线宽统一 1.5–1.6px，圆角处理与主视觉体系一致，不使用实心填充图标（记忆核心图标除外，因其是品牌标记而非功能图标）
