## 一、信息架构

### 1.1 模块树（评审回填：主航收敛）

v1 初稿把 11 个入口平铺进 76px 侧栏，主航过载（评审共识）。**v1.1 收敛为"主航 6 项 + 路线页 + 设置内系统分区"**：

| 层 | 内容 |
|---|---|
| **主航（Phase 0 起常驻）** | ◧ 扫描仪表盘 · ⌕ 检索 · ◈ 关联图谱 · ▤ 记忆库 · 🔒 隐私与推理 · ⚙ 设置 |
| **仪表盘右列卡（随 Phase 点亮）** | 项目摘要卡（Phase 1，v1 初稿中"摘要"模块的落点）、健康度摘要卡（Phase 1）、狗粮进度卡（Phase 2）、每周回顾统计卡（Phase 2，**非独立导航页**） |
| **托盘/角标（Phase 3）** | 主动提醒 = 系统托盘角标 + 应用内 badge，不占主航（v3 Phase 3a 拉取式主路径） |
| **设置 → 系统分区** | Agent 工件（读取源 Phase 1 / 导出 Phase 4）、适配器状态（Phase 2）、评测集管理 |
| **路线页（未来能力收纳）** | 所有未到 Phase 的功能集中一页：每项 = 图标 + 名称 + 一句话价值 + `gated_by` 解锁条件 + 当前进度（如提醒："基于真实使用数据校准，已积累 x 次"） |

**置灰解锁原则维持**（状态诚实），但形态改为"路线页"集中呈现，主航不预埋占位图标；每项可键盘聚焦（Tab/Enter 打开说明）。隐私图标使用规范 `nav-icons.svg` 既有隐私 symbol，不复用 🔒 锁定隐喻（锁定 = 功能未解锁，两者语义不同）。规范中的 `icon-summary` symbol 废止，映射改为仪表盘项目摘要卡。

### 1.2 全局框架子模块

| 子模块 | 细节 |
|---|---|
| 顶部常驻栏（**新增骨架规范**） | 高 44px，独立玻璃层（`blur(20px)`，与卡片同层不叠新模糊值）；左：当前 scope（路径+分支，mono，点击展开切换器）；右：资源状态轨（2.3）+ 命令面板触发器（文案"命令面板"而非"搜索"，快捷键 `Ctrl+K / ⌘K`——**平台双写**，规范 §五的 `⌘K` 单写废止） |
| 命令面板 | 两个分区：`前往`（页面/任意 KO，`#` 前缀 + id 片段）/ `系统动作`（运行评测、重启 sidecar 等重操作——**触发前二次确认**）；检索页是命令面板的其中一项，不是唯一用途 |
| 通知层级（评审回填修订） | 三级：`inline`（默认）/ `badge`（导航与托盘角标）/ `toast`（**仅错误**，可静音）。**授权确认不走 toast**——统一走 7.2 页内确认流，且**不可静音**；提示音归"环境反馈"类（默认关），不新增通知层级 |
| 空态四态表（评审回填，全模块强制） | 每个模块必须定义四态：`loading`（骨架）/ `empty-unindexed`（尚未扫描，引导动作）/ `empty-indexed`（已扫描无结果，数据事实文案）/ `error`（错误+重试）。健康度"0 过时 0 矛盾"是**成功空态**，用 jade 正向呈现，不用"暂无数据" |

## 二、UI 规范增补（v1.1 回填后）

### 2.1 置信度与排序展示语义（回填修订：v1 两处错误已修正）

- **排序语义（修正）**：校准门禁通过前，关闭的**仅是 `confidence` 降权**；`freshness` 按确定性规则（git/hash/mtime）**照常参与排序**。排序依据摘要全产品统一为一句话：**`排序：BM25(FTS5) + 向量 RRF 融合 · freshness 规则生效 · 置信度降权未启用（未校准）`**，后半句校准后自动更新。v1 中"关键词+语义+时间衰减"与"RRF·时间衰减"两种表述合并废止。
- **未校准分数的展示（修正）**：**不做"低/中/高"档位映射**（那是另一层未声明的分档）。未校准时 UI 只显示灰色微徽标 `未校准`；点开详情层（**点击/Enter 展开，非 hover-only**——键盘可达是"状态诚实"的前提）显示"模型原始分 · 未校准 0.72"。校准后展示 `calibration_version` 与区间。
- **结果卡片不显示"相关度 %"**（维持）。

### 2.2 引用芯片（RefChip，回填修正）

- 主视觉：`[类型图标] 标题（≤24 字符）· id 短码（mono 6 位）`；
- 展开详情（点击/Enter，hover 仅轻预览）：**全量 KO id + content_hash + 关联 commit + 路径（标注"辅助引用"）**——compaction 稳定引用的完整契约（v3.1 §五），短码仅是主视觉省略而非契约本体；
- 键盘：RefChip 有 focus ring；列表中 `j/k` 移动、`Enter` 进详情；
- 验收（可观察行为两条）：只剩 KO id 时仍能打开 Context Bundle；截断重注入后 id 不变。

### 2.3 资源状态轨（回填修正：灯位职责重划）

| 灯位 | 状态（用户向命名，不带内部 L* 编号） | 说明 |
|---|---|---|
| 推理（sidecar） | `空闲 / 已加载·待命 / 决策中 / 生成中` | **只反映 llama.cpp sidecar**（L1.5/L2）；"已加载·待命"与"计算中"用不同样式（呼吸 vs 常亮）；详情卡 = 当前驻留模型 + 占用 + `n_ctx` 硬顶 + 最近卸载原因回放 |
| 索引（管线） | `空闲 / 扫描中 / 向量化中` | 反映扫描队列与 **embedding（ort）作业**——embedding 不走 sidecar，两盏灯不得互相声称"模型在工作" |
| 边界 | `仅本地 / 云端已启用` | loopback 门状态摘要（7.1） |

**"L1 常驻"等能力轴编号不出现在灯位**（回填：用户向命名；能力轴 L0/L1/L1.5/L2/L3 只存在于推理档位卡的说明层）。互斥排程（embedding ↔ L1.5 ↔ L2 单驻留）在推理灯详情卡的回放时间线中解释。

### 2.4 主题、密度与快捷键

- 深色优先维持，浅色 P2；密度两档（紧凑 28px / 舒适 36px 行高）**全局设置优先**，检索列表的本地记忆仅在未设置全局时作为默认；紧凑模式卡片内边距降为 16px（v1 遗漏，避免"假紧凑"）；
- 快捷键一律平台双写（`Ctrl/⌘`）。

### 2.5 coral 边界规则（回填修订）

coral = **硬边界**（出云门、评测门禁失败、**待确认**矛盾）。已确认矛盾的持久呈现**降级为小面积徽章**（列表行尾 + 图谱节点角落 6px 角标），**不做整圈节点描边**——矛盾会长期存留在库中，整圈 coral 会让日常界面铺红，违反"日常无红色"原则。过时候选维持虚线中性。

### 2.6 可达性条款（回填新增）

**所有"诚实说明"（未校准分数、freshness 依据、排程回放、边类型）不得只存在于 hover**——一律提供点击/Enter 展开的等价面板；hover 仅作预览加速。全部可交互元素有 focus ring（规范 §七工程化）。

### 2.7 动效预算（维持）

呼吸核心唯一长动效；微交互 140ms；面板切换 220ms；全部 `prefers-reduced-motion` 降级。

### 2.8 图标资产增补表（回填新增）

| 新增 symbol | 用途 | 交付批次 |
|---|---|---|
| `icon-library` | 记忆库 | HTML 第一批 |
| `icon-route` | 路线页 | 第一批 |
| `icon-health` | 健康度摘要卡 | 第二批 |
| `icon-digest` | 每周回顾卡 | Phase 2 批次 |
| `icon-artifact` / `icon-adapter` | 设置·系统分区 | Phase 2 批次 |
| `icon-summary` | **废止**（映射至项目摘要卡，复用 `icon-health` 风格） | — |

线宽 1.5-1.6px、`currentColor`，遵循规范 §十。

### 3.1 子模块（每项标注最早 Phase / 未到形态）

| 子模块 | Phase / 未到形态 | 细节 |
|---|---|---|

| 狗粮进度卡 | **P2** | **只展示已积累使用次数**（"已积累 x 次"）；解锁阈值 N 基线未定（回填：不虚构 x/N 分母），显示"阈值将随真实使用校准后公布" |
| 每周回顾统计卡 | **P2**（v1.1 降级：仪表盘卡，非独立导航页；**非 Phase 2 退出标准**，属深化建议延伸） | 仅 L0 统计 + 固定模板文案；L2 综述与模式识别 Phase 4 才出现，界面不得提前画"由本地模型生成"段落 |

### 3.2 扫描队列状态机（回填修订：按管线阶段展开）

```
queued → parsing → chunking → embedding → linking → done
   │         │         │          │          │
   └─ 任一阶段可 → failed(带阶段位点 + 一句话错误 + 重试该阶段)
cancelling（用户取消，当前阶段完成后停止，不产生半写状态）
```

- 徽章与状态机一致：`解析 → 分块 → 向量化 → 关联` 四阶段徽章即状态机的中间态，v1 的"等待中→解析中→失败→完成"四态简化版**废止**；
- **embedding 阶段不引用 sidecar**（回填修正：embedding 走 ort，v1"等待本地推理服务"文案错绑运行时）；等待 sidecar 的阶段是**摘要/抽取任务行**（P1 起出现），行内显示"等待推理服务"并链接到 7.1 sidecar 卡。

### 3.3 空态

`empty-unindexed`："尚未扫描任何工作区" + 选择工作区按钮；`empty-indexed`（队列空且已有索引）："索引已是最新，等待文件变更"；`error`：全局管线失败横幅（非弹窗）+ 重试。
