# ADR-012：扫描页策略

## 状态

Accepted

## 背景

PDF 默认走文本层提取。无文本层或文本过短的扫描页若在默认路径上调用视觉模型，会把视觉转写绑进 Phase 0 索引，并挤占摘要模型的输出预算。

## 决策

- **默认只提取文本层**（pdf-extract / lopdf，与 v3 相同）。判定为扫描页（无文本层或文本过短）则标记并跳过，不阻塞索引。
- **视觉转写是 Phase 2+ 的显式增强**，由用户显式触发。使用独立的输出 token 预设，不套用摘要的短上限。设每文档页数上限、图像最长边限制，超时则回退到 OCR。
- 独立 OCR 在 Phase 2 可插拔。基线不写"视觉优先"。
- 视觉不进 Phase 0 冒烟范围。

## 备选方案

- 默认对扫描页跑视觉模型：视觉进入默认摄取路径，且中文密集表格、代码截图的质量常不如专用 OCR。
- 跳过且不标记：用户看不到缺了哪一页。

## 后果

- 摄取状态必须能表示"扫描页跳过"，与解析失败分开。
- 风险表记下"视觉解析拖垮索引 Job"。配额（页数、最长边、超时）在实现 change 里写成配置，不在本 ADR 新造未测数字。
