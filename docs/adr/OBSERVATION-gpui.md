# 观察记录：GPUI（不占 ADR 编号）

## 状态

观察。不是决策，不进入 ADR 编号序列。

## 背景

GPUI 可以做独立桌面应用（Windows 走 Win32 + DirectWrite），但本体仍是 pre-1.0：高频破坏性变更、零 widget、Windows 后端最年轻，IME 与无障碍有差距，没有热重载。

## 观察

**v1 UI 维持 Tauri 2，不切换 GPUI。** 理由有三条：Windows 中文 IME 是硬伤；液态玻璃视觉语言是 Web 原生优势；UI 是薄面，不承担 pre-1.0 的接口抖动。

重评估要 **三条同时满足**，才单独立项：

1. GPUI 1.0，且 Windows IME 与无障碍补齐。
2. gpui-kit 独立稳定发布。
3. WebView2 渲染玻璃效果在目标机型上出现可测的性能问题。阈值示例：1080p 主面板交互，30 秒内 GPU 占用或掉帧超过阈值。写成可测条件；测不到就既不触发、也不需要触发。

三条未同时满足之前，不引入 GPUI 依赖，不改壳的选型。
