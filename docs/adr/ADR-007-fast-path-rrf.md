# ADR-007：Fast Path RRF 融合

## 状态

Accepted

## 背景

v2 的轻量路径是"关键词 → 向量 → 直接返回"的串行结构，没有融合。v3 改为 RRF。v3.1 进一步规定：未校准的 `confidence` 不得参与这次降权。

## 决策

- Fast Path：FTS5 与向量 **各取 top-k**，**RRF 融合后返回**。BM25 只来自 SQLite FTS5（ADR-001）。
- `freshness` 保持确定性规则（git / hash / mtime），低于阈值时降权。它不走模型打分。
- `confidence` 低于阈值的降权 **只消费校准后的值**。校准门禁通过前，该降权关闭。校准前排序只用确定性信号。
- 原始分记在 `model_confidence`，校准分记在 `confidence`。`schema_valid` 不等于原始分，也不等于校准分（ADR-010）。
- Deep Path 按需触发，是产品延迟策略。它的增益由 Phase 1 评测集在工程记忆任务上验证。Phase 1 的确定性结构边进入 Fast Path 的过滤与图遍历，不放到 Deep Path 里等待评测。
- LoCoMo 一类对话记忆证据不能外推到解析器产生的确定性结构边。LLM 抽取的模糊关系图不作为默认检索路径。

## 备选方案

- 维持 v2 的串行"关键词然后向量"：没有融合。
- 校准前就用口头分降权：未校准分数会污染排序。这是 v3.1 明确关闭的路径。

## 后果

- 对外说明排序时，置信度降权标为未启用，直到校准上线。
- 校准本身是路线图外后置项，不在本 ADR 排期。
