# ADR-009：借力 vs 自研决策门

## 状态

Accepted

## 背景

2026 年已有多个开源 MCP 代码索引器覆盖 Phase 0–2 的索引面。索引面可以对齐，记忆面（知识对象、freshness、commit 绑定、矛盾检测）不是这些索引器的交付物。解析层若既不自研也不包装，Phase 0 结束时没有可执行结论。

## 决策

- 解析 / 索引层在 **Phase 0 结束前二选一**，输出一页 ADR：自研薄索引，或包装外部索引器（许可证限 Apache-2.0 或 MIT）。
- 判断点是数据模型映射：外部索引器的图是符号图，Mnemex 的核心是 Knowledge Object。**阻抗在数据模型映射，不在许可证**。
- 嵌入 C / TypeScript 索引器的映射成本，与自研 Rust 管线的成本，在同一次 spike 里对比。
- 竞品功能矩阵作为 Phase 1 交付物时，必须带仓库、许可证、提交日期。路线图表还要求解析级别列。

## 备选方案

- Phase 0 之前就全部自研：没有与包装方案的同场成本对比。
- 以许可证作为唯一否决项：Apache/MIT 索引器仍可能在知识对象映射上阻抗过高。

## 后果

- 本 change 不实现解析器，也不预选某一外部索引器。
- 结论页在 Phase 0 末的 change 里归档。若结论是替换已定的存储或图选型，再开新的编号 ADR。
