# ADR-008：Phase 1 回归评测集门禁

## 状态

Accepted

## 背景

分块、排序、抽取的改动需要一把固定的尺子。这把尺子用来防止退步，不用来证明"优于免费索引器"。

## 决策

- 定位是 **回归门禁**：调整分块策略或排序权重后不得回退。
- 三类任务，每类不少于 15 条（确切条数在详细设计中定）：结构查询（symbol / 调用边）、决策召回、过时检测。区分冒烟集与回归集。
- 同一评测集还承载 code embedding 的 A/B（候选 × Qwen3-Embedding-0.6B × BM25+symbol 基线）和决策抽取质量验证。
- 竞品对比如果要做，留在 Phase 2，且必须同仓库、同 query 集。
- 不编造无法复核的总分或分母。报告写通过情况与失败条目。

## 备选方案

- 用公开榜单代替内部集：榜单任务不是这三类工程记忆任务。
- 在 Phase 1 做竞品对比：没有稳定的同仓库 query 集。

## 后果

- 评测集条目由后续 change 落入仓库。本 ADR 只固定门禁语义。
- Phase 1 结构图谱的调用边精度在回归集里单列（v3 §4.1），类型解析可以后做，但不得默默降成名字匹配。
